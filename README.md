Housing Market Analysis

Project Overview

This project analyses housing market data to explore property prices, property values, and differences across cities.

The analysis was conducted using Microsoft Excel, Power Query, and Power Pivot to clean, transform, model, and analyze the data.

Project Objectives

The objectives of this project were to:

•	Examine property prices across different cities.
•	Calculate key performance indicators, including average and median property prices.
•	Identify cities with the highest average property prices.
•	Investigate the relationship between property characteristics and prices.
•	Identify data quality issues and prepare the dataset for analysis.
•	Present findings through charts, PivotTables, and an Excel dashboard.

Dataset Information

•	Dataset Name: House Price Prediction
•	Source: Kaggle
•	Original Filename: modified data.csv
•	Working Filename: Housing Dataset.csv

The dataset was cleaned and prepared before analysis.

Tools and Techniques

•	Microsoft Excel: Data analysis and visualisation.
•	Power Query: Data cleaning and transformation.
•	Power Pivot: Data modelling and calculations.
•	PivotTables and Charts: Exploratory data analysis and presentation.

Data Cleaning

The data preparation process included:

•	Checking for missing and zero values.
•	Investigating records with zero property prices.
•	Reviewing data quality issues.
•	Transforming and preparing data for analysis.

Key Performance Indicators

The analysis examined:
•	Total property value.
•	Average property price.
•	Median property price.
•	Average price per square foot.
•	Number of properties analysed.

Key Findings

The analysis explored differences in property prices across cities and examined how property characteristics related to property values.

The final findings and supporting figures are presented in the Excel workbook and project report.

Project Files

•	Analysis: Completed Excel workbook.
•	Data: Dataset source information.
•	Visualizations: Dashboard and charts.
•	Report: Housing market analysis report.

Conclusion

This project demonstrates the application of Excel, Power Query, and Power Pivot to data cleaning, data modelling, exploratory analysis, and dashboard development.

It highlights how structured data analysis can help uncover patterns in housing prices and support data-driven decision-making.
