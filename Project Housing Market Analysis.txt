Project: Housing Market Analysis

Dataset Name: House Price Prediction

Source: Kaggle

Dataset URL: https://www.kaggle.com/datasets/debayank2024/house-price-prediction

Original Format: modified_data.csv

Purpose: The dataset was used to analyze housing market data, investigate property prices across cities, examine property characteristics, and identify insights to support data-driven decision-making.

Data Preparation: The original dataset was cleaned and transformed using Microsoft Excel and Power Query before further analysis using Power Pivot.
